# BongoliciousCat 🐱🥁

An interactive Bongo Cat that plays drums when you press keys or tap buttons. Pure HTML, CSS, and JavaScript - no dependencies!

🎮 **[Play Now](https://enricjake.github.io/BongoliciousCat/)** | See the cat in action!

## How to Play

- **A / ←** — Left drum
- **D / →** — Right drum
- **Space** — Both drums at once
- **Click/Tap** — Hit the drums directly

## Features

- 🎵 Web Audio API synthesized drum sounds
- 👀 Cat's eyes follow your cursor/finger
- 😊 Expressive face with blinking, blushing cheeks, and happy reactions
- 🔥 Combo counter — keep hitting to build streaks
- 🎉 Streak celebrations at 5, 10, 25, 50, and 100 hits
- ✨ Musical notes and particles burst from drums
- 📱 Mobile-friendly with touch controls
- 🔊 Sound toggle (saved in localStorage)
- ♿ Respects `prefers-reduced-motion`

## Running Locally

Just open `index.html` in your browser. No server needed!

```bash
# Clone the repository
git clone https://github.com/enricjake/BongoliciousCat.git
cd BongoliciousCat

# Open in your browser
open index.html
```
